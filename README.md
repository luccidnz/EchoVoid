# Ech0Void V2

Ech0Void is a local-first experimental ITC audio instrument for Android/iOS built with React Native + Expo.

This rebuild replaces the old disconnected test navigator, placeholder transmission screen, random dictionary/TTS capture path and empty noise-bank assets with a functioning three-engine instrument.

## Install directly on an Android phone

Every push to `rebuild/ech0void-core-v2` now builds an installable Android APK on GitHub Actions and publishes it to the repository's **Ech0Void V2 Phone Build** prerelease.

On the phone:

1. Open the GitHub repository.
2. Open **Releases**.
3. Open **Ech0Void V2 Phone Build**.
4. Download `Ech0Void-v2-phone.apk`.
5. Allow installation from your browser/GitHub app if Android asks.
6. Tap the APK and install it.

This test APK runs directly on the phone. It does not require VS Code, Termux, Expo Go, Metro, a USB cable, or a computer after installation.

## The three channels

- **EchoBox** — locally generated vocal-like fragments, layered overlaps and decaying echoes.
- **Field Drift** — reverse fragments, rate drift, jumpy timing and deliberate dropouts.
- **Signal Scan** — procedural static beds, gated scan chirps and sparse fragments.

The audio source bank is synthesized on-device into WAV files. Nothing in the core requires downloaded speech, a cloud service, a hidden word list, or a remote backend.

## Provenance first

Every piece of audio generated by Ech0Void is written into the session **Source Ledger** with a timestamp, source ID, effect, playback rate and sensor-influence value. The room microphone recording is stored separately when permission is granted.

This matters because speaker output can bleed back into a microphone recording. The ledger gives investigators a direct contamination reference rather than presenting app-generated audio as unexplained evidence.

## Sensors

Magnetometer + accelerometer changes can influence timing/selection according to the **Sensor Mix** control. Sensor data is input to the instrument; it is not labelled as proof of a paranormal cause.

## Local session vault

Sessions save locally with:

- mode and control settings
- room recording URI (when available)
- manual marked moments
- sensor summary
- complete generated-source ledger
- user notes
- shareable JSON evidence/provenance export

No backend is required for V2 core operation.

## Run through Expo during development

```bash
npm install
npm run go
```

Scan the QR code with Expo Go. Microphone access is optional for the generated channels but required to create the room recording.

## Validate the pure core

```bash
npm test
npm run typecheck
```

## Product boundary

Ech0Void is an experimental audio/ITC instrument. Generated fragments, sensor changes, perceived words and recordings do not by themselves establish a paranormal cause. See `docs/ECH0VOID_VISION.md` for the non-negotiable architecture and anti-drift rules for future work.
