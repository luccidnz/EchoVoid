# Ech0Void Native V3 — Corrected Product Truth

## Core identity

Ech0Void is an experimental ITC / ghost-box-inspired signal instrument, not a spooky procedural synthesizer.

The primary instrument is **Ech0Gate**.

## Ech0Gate interaction

- a wordless human sound bank continuously advances beneath a closed gate
- the user asks a question
- the user manually opens the gate for roughly 1–3 seconds
- releasing the control closes the gate
- the gate never opens itself
- reverb/tail is optional
- sensor bias is optional and may only alter the hidden bank position/selection; it cannot create words or autonomously expose audio

## Wordless-bank truth

The source design follows the openly described HSB principle: recorded human speech is reversed, slowed to around half speed, chopped into ~2-second output fragments and shuffled.

Ech0Void must improve on that baseline by making the bank implementation auditable and non-repetitive:

- each named Vox bank must be backed by genuinely different recorded source material
- a preset may not merely relabel the same source
- banks must be long enough that normal intermittent use does not reveal obvious short loops
- source quality must be high enough to preserve real differences in voice timbre
- VOID MIX may combine multiple independent voices
- the hidden bank must keep moving while the gate is closed
- selecting or reshuffling a bank must produce a new chunk order
- provenance must identify app-sourced recorded-bank audio separately from generated static

## Secondary engines

EchoBox, Field Drift and Signal Scan remain experimental secondary modes. They must not distract from proving Ech0Gate first.

## Hard anti-drift rules

Do not reintroduce:

- tiny source clips presented as separate banks
- multiple presets that all use the same source pool
- obvious short loops
- 8-bit crunchy source audio as the default voice bank
- continuous synthetic vowel/formant generators as the main voice source
- constant procedural chirps
- constant noise beds
- random dictionary words presented as communication
- TTS pretending to be an entity
- AI-generated spirit messages in the live capture path
- fake sensor/anomaly values
- claims that a sensor spike proves paranormal activity

## Physical-phone acceptance

Ech0Gate is not accepted until:

1. at least several individual banks are immediately distinguishable by ear
2. no selected bank obviously repeats the same short warped phrase during normal use
3. VOID MIX clearly rotates across different human timbres
4. the bank remains silent until the user opens the gate
5. releasing the gate closes it reliably
6. reverb-off makes the raw wordless source easy to audit
7. sensor bias 0% gives a purely manual session
8. room capture remains separate and replayable
9. each gate exposure is represented in the evidence ledger
